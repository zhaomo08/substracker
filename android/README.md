# SubsTracker Android

This is a lightweight Android WebView wrapper for the deployed SubsTracker Worker.

Build a debug APK:

```bash
ANDROID_HOME="$HOME/Library/Android/sdk" /Users/mesay/.gradle/wrapper/dists/gradle-8.12-all/ejduaidbjup3bmmkhw3rie4zb/gradle-8.12/bin/gradle -p android assembleDebug
```

The debug APK is generated at:

```text
android/app/build/outputs/apk/debug/app-debug.apk
```
